## Neroki Dotfiles ( ᴗ͈ˬᴗ͈)ഒ
- **Sys:** Arch Linux<br/>
- **Compositor:** Wayland<br/>
- **WM:** Niri<br/>
- **Launcher:** fuzzel<br/>
- **Shell prompt:** starship<br/>
- **Terminal:** foot/zsh<br/>
- **Shell:** DankMaterialShell (DMS)<br/>

### Manual
you'll find everything on [/.config](https://github.com/neroki194/niri-dotfiles/edit/main/.config), no steps, use your brain.

### Quick & Easy
just clone the repo and follow the steps:<br/>

```bash
git clone https://github.com/neroki194/niri-dotfiles
cd niri-dotfiles && cd install
./setup.sh
```
